# TalkHero Language Policy

**Version:** 1.0  
**Status:** RC1

## Основне правило

Увесь інтерфейс TalkHero використовує українську мову.

## Українською мовою мають бути

- навігація;
- назви розділів;
- кнопки;
- підказки;
- системні повідомлення;
- повідомлення про помилки;
- стани завантаження;
- налаштування;
- статистика;
- пояснення;
- навчальний зворотний зв’язок;
- повідомлення про успіх;
- повідомлення про відсутність даних;
- тексти доступності та `aria-label`.

## Англійська мова використовується лише для навчального матеріалу

Допустимі приклади:

- репліки NPC;
- англійські слова;
- речення для перекладу;
- варіанти відповіді;
- вправи на вимову;
- природні англійські формулювання;
- назви реальних місць або навчальних сюжетів, якщо це частина контенту.

## Заборонено

- змішувати українську та англійську в системній навігації;
- використовувати англійські назви службових кнопок;
- залишати неперекладені повідомлення про помилки;
- використовувати пошкоджене кодування;
- показувати англійський службовий текст без навчальної причини.

## Перевірка перед релізом

Кожен новий екран перевіряється на:

1. українську мову всіх службових елементів;
2. відсутність пошкодженого кодування;
3. правильне розмежування інтерфейсу та навчального контенту;
4. зрозумілі українські тексти доступності.
