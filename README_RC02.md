# TalkHero RC-02 — Clothes Shop

## Встановлення

Розпакуйте пакет у `C:\TalkHero\Web`.

```powershell
npx supabase db push
npx tsc --noEmit
npm run dev
```

## QA

1. Clothes Shop розташована після Post Office.
2. До завершення Post Office вона заблокована.
3. Після завершення Post Office вона відкривається.
4. Усі 18 сцен проходяться.
5. Нараховується 70 XP і 24 монети.
